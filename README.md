# Guide till Grok Bot

En enkel, inofficiell en-sidig webbplats på svenska om hur man kommer igång med [Grok Bot](https://docs.x.ai/grok-bot) och vad assistenten kan hjälpa till med.

Öppna `index.html` i en webbläsare, eller publicera repot på Vercel. Det behövs inget byggsteg och inga miljövariabler. Vercel känner igen de statiska filerna i roten.

Sidan är inte en officiell xAI-sida. Texten är en kort sammanfattning av den offentliga dokumentationen och kan bli inaktuell.

Typsnitten Fraunces och Outfit ligger i `fonts/` och används under SIL Open Font License. Licenserna finns i samma mapp.
